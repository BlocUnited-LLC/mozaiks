# Roadmap

This folder tracks the gaps, priorities, and planned work for Mozaiks.

| Document | Purpose |
|----------|---------|
| [gap-analysis.md](gap-analysis.md) | Full audit of what exists, what's missing, and severity |
| [priorities.md](priorities.md) | Ordered work items grouped by priority |
| [primitive-extension-roadmap.md](primitive-extension-roadmap.md) | Controlled path for adding new platform-owned primitives, patterns, and subsystem contracts |
| [mfj-authoring-roadmap.md](mfj-authoring-roadmap.md) | Baseline vs advanced MFJ authoring rollout and deferred integration knobs |
| [mfj-build-decomposition-contract.md](mfj-build-decomposition-contract.md) | Build-oriented MFJ decomposition contract examples |

## How to Use

1. Check **gap-analysis.md** for the current state of each area
2. Check **priorities.md** for what to work on next
3. When a gap is closed, update both documents

## Rules

- Keep items actionable and specific
- Update status when work starts or completes
- Don't duplicate planning that lives elsewhere (e.g. GitHub Issues)
