# Using Studio

Studio opens automatically when you run `quickstart` or `studio --open`.

```text
http://localhost:3000
```

## Build an app

1. Click **Create App**
2. Describe the product you want to build in the chat
3. The AI walks you through planning, design, and generation
4. Review the generated output and promote it when ready

Everything happens in the chat — there's no separate form wizard.

## Come back to a build

Drafts are saved automatically. If you close Studio mid-build, reopen it with:

```powershell
python -m mozaiks studio --dir .\my-workspace --open
```

Then click **Continue Build** on any draft app.

## After promoting a build

Click **Open App** to access the app-specific view — settings, usage stats,
integrations, and admin pages for that specific app.
