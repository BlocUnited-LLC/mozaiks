# Common Ground

An interactive community reference for the web-journey milestone in ADR 0013.
This workspace exercises the existing social capability pack through the normal
Mozaiks platform host and shared React shell.

## Implementation scope

- Public posts, comments, reactions and author-controlled deletion.
- App-specific branding and responsive desktop/phone browser layouts.
- Real module HTTP requests and durable MongoDB records in local acceptance.
- Explicit loading, empty, error and retry states.

Implementation and acceptance are in progress. This reference does not establish
PWA installation, native mobile delivery, private/friends-only content, managed
hosting or production readiness.
